# 共通ユーザーマニュアル

チームメンバー向けのタスク管理アプリ操作手順です。管理者はグループの作成者であり、メンバーは所属ユーザーです。

## 共通

### ユーザー登録

1. `http://localhost/register` を開きます。
2. ユーザー名とパスワードを入力します。
3. 「登録」を押します。
4. 「登録が完了しました」と表示されたことを確認します。

### ログイン

1. `http://localhost/login` を開きます。
2. ユーザー名とパスワードを入力します。
3. 「ログイン」を押します。
4. ホーム画面が表示されたことを確認します。

## 管理者向け操作

### グループを作成する

1. ホーム画面で「グループを作成」を押します。
2. グループ名を入力します。
3. 作成操作を完了すると、所属グループ一覧と参加IDが表示されます。
4. 作成したグループが一覧に表示され、作成者は管理者として扱われることを確認します。

参加IDは、グループ一覧のグループ名と併せて表示される6桁の英数字です。

### グループを解散する

1. 対象グループを選択します。
2. 「グループを解散」を押します。
3. 確認に応答します。
4. 対象グループ、所属関係、対象グループの全タスクが削除され、ホーム画面へ戻ることを確認します。

他のグループのタスクやグループは削除されません。

### 全タスクを削除する

管理者はグループ画面で所属グループ内のタスクを削除できます。対象タスクの「削除」を押すと、作成者ではないタスクも削除されます。

## メンバー向け操作

### グループに参加する

1. ホーム画面で「グループに参加」を押します。
2. 参加IDを入力します。
3. 「参加」を押します。
4. 所属グループ一覧にグループが表示されたことを確認します。

存在しない参加IDや解散済みの参加IDでは参加できず、エラーが表示されます。

### グループ画面を開く

1. 所属グループ一覧で対象グループを選択します。
2. 選択したグループのタスクだけが表示されることを確認します。
3. 別のグループへ移動した場合、前のグループのタスクは表示されません。

### タスクを作成する

1. 対象グループ画面で「タスク登録」を押します。
2. タスク内容、担当者、状態を入力します。
3. 開始日時、終了日時は必要に応じて任意入力します。
4. 「登録」を押します。
5. 選択中のグループの一覧にタスクが表示されたことを確認します。

日時の入力は次のとおりです。

- 両方未入力: 一覧で「期限なし」と表示します。
- 開始日時のみ: 終了日時は「期限なし」として扱います。
- 終了日時のみ: 開始日時には登録処理時の現在時刻が設定されます。
- 終了日時を開始日時より前にすると登録できず、時刻の順序を示すエラーが表示されます。

### タスクを編集する

1. 対象タスクの「編集」を押します。
2. 内容、担当者、状態、日時を変更します。
3. 日時は未入力または有効な組み合わせへ変更できます。
4. 「更新」を押します。
5. 同じグループの一覧に変更内容が反映されたことを確認します。

### 自分のタスクを削除する

1. 自分が作成したタスクの「削除」を押します。
2. タスク一覧から消えたことを確認します。

メンバーは他のメンバーのタスクを削除できません。グループ管理者だけが他メンバーのタスクを削除できます。

## 注意事項

- 操作にはログインと対象グループへの所属が必要です。
- Windowsでポート80を使用する場合、管理者権限が必要になることがあります。
- ポート80が別のアプリケーションで使用中の場合、起動できません。
- 開発用データベースのため、アプリ再起動時にデータが初期化されます。
