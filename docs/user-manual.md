# 共通ユーザーマニュアル

チームメンバー向けのタスク管理アプリ操作手順です。

## ユーザー登録

1. `http://localhost:8080/register` を開きます。
2. ユーザー名とパスワードを入力します。
3. 「登録」を押します。
4. 「登録が完了しました」と表示されたことを確認します。

## ログイン

1. `http://localhost:8080/login` を開きます。
2. ユーザー名とパスワードを入力します。
3. 「ログイン」を押します。
4. タスク一覧画面が表示されたことを確認します。

## タスク一覧の確認

ログイン後の「タスク一覧」で、登録済みタスクを確認できます。

各タスクには以下が表示されます。

- タスク内容
- 担当者
- 状態
- 開始日時
- 終了日時

## タスクの登録

1. 「タスク登録」を押します。
2. タスク内容、担当者、状態、開始日時、終了日時を入力します。
3. 「登録」を押します。
4. タスク一覧に表示されたことを確認します。

## タスクの更新

1. 対象タスクの「編集」を押します。
2. 内容を変更します。
3. 「更新」を押します。
4. タスク一覧に変更内容が反映されたことを確認します。

## タスクの状態変更

1. 対象タスクの「編集」を押します。
2. 状態を「未着手」「進行中」「完了」から選択します。
3. 「更新」を押します。
4. タスク一覧で変更後の状態を確認します。

## タスクの削除

1. 自分が作成したタスクの「削除」を押します。
2. タスク一覧から消えたことを確認します。

削除できるのは作成者本人だけです。

## 注意事項

- 操作にはログインが必要です。
- 必須項目が未入力の場合、登録・更新できません。
- 開発用データベースのため、アプリ再起動時にデータが初期化されます。
