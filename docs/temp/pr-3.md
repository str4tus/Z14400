## 変更内容
- H2インメモリデータベースの接続設定と、ユーザー情報を保存する`users`テーブルを追加した。
- ユーザー情報を表す`User`クラスと、ユーザー検索・登録を行う`UserMapper`を追加した。
- `/register`のGET/POST処理を`AuthController`に追加した。
- ユーザー名とパスワードを入力できる登録画面を追加した。
- 登録成功時の完了表示と、登録済みユーザー名の重複エラー表示を追加した。
- 登録画面表示、登録成功、重複登録拒否を確認する自動テストを追加した。
